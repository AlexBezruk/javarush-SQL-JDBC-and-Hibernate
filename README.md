# 🧠 SQL vs Redis — Сравнение скорости доступа к данным

Java-приложение для сравнения производительности MySQL (через JDBC и Hibernate) и Redis.  
Проект создан в рамках финального задания модуля **Java Professional** на [JavaRush](https://javarush.com).  
Цель — измерить, насколько быстрее Redis по сравнению с традиционной реляционной базой данных при получении случайных записей.

---

## 🚀 Возможности

- ⚡ **Сравнение скорости**: измерение времени доступа к данным из MySQL и Redis
- 🧮 **Статистика запросов**: количество, среднее время, общее время
- 🧑‍💻 **JDBC и Hibernate**: два способа доступа к MySQL
- 🗃️ **Кэширование**: загрузка данных из MySQL в Redis для последующего сравнения
- 📊 **Вывод результатов**: консольный отчёт о производительности

## ⚙️ Как работает программа

Приложение запускает серию запросов к MySQL и Redis, измеряя время выполнения.  
Данные сначала загружаются из MySQL, затем кэшируются в Redis.  
После этого выполняются случайные выборки, и фиксируется статистика.

### 🧩 1. Инициализация
- Загружается дамп базы данных `dump-hibernate-final.sql`
- Устанавливается соединение с MySQL и Redis

### 🔄 2. Загрузка данных
- Данные из MySQL извлекаются через JDBC и Hibernate
- Все записи сериализуются и сохраняются в Redis

### ⏱️ 3. Тестирование скорости
- Выполняются случайные выборки по ID
- Измеряется время доступа для каждого источника
- Выводится статистика: общее время, среднее, количество
